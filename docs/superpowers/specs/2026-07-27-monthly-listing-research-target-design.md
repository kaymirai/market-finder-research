# 月間出品目標から逆算する勝ち候補探索 設計

## 目的

Market Finderの連続探索を「A/B候補を1件見つけたら停止」から、「月間出品目標を達成するために必要なA/B候補数を確保したら停止」へ変更する。

初期設定は次のとおりとする。

- 月間出品目標: 100商品
- 月間リサーチ回数: 4回（週1回）
- A/B候補1件から作る商品数: 5商品
- 1回のリサーチ目標: A/B候補5件

計算式は次とする。

`1回のA/B目標件数 = ceil(月間出品目標 ÷ 月間リサーチ回数 ÷ 1候補から作る商品数)`

## UI

「勝ち候補の連続探索」パネルに「出品目標から逆算」欄を追加する。

入力項目:

- 月の出品目標
- 月のリサーチ回数
- A/B候補1件から作る商品数

入力直下に次を常時表示する。

- 1回あたりの出品目標
- 今回必要なA/B候補数
- 現在の進捗
- 残り件数

初期表示例:

`月100商品 ÷ 4回 ÷ 5商品 = 今回A/Bを5件確保`

探索中の表示例:

`A/B候補 1 / 5件・残り4件`

探索ボタンは状態に応じて次の文言を使う。

- 未開始: `目標まで勝ち候補を探す`
- 一時停止: `目標まで探索を再開`
- 目標達成: `今週の探索を完了`
- 目標達成後に追加探索する場合: `さらに強い候補を探す`

## 逆算ルール

- 月間出品目標、月間リサーチ回数、1候補から作る商品数は1以上の整数に正規化する。
- 月間出品目標の上限は1,000、月間リサーチ回数の上限は31、1候補から作る商品数の上限は50とする。
- 1回あたりの出品目標は `ceil(月間出品目標 ÷ 月間リサーチ回数)` とする。
- 今回必要なA/B候補数は `ceil(1回あたりの出品目標 ÷ 1候補から作る商品数)` とする。
- 初期値100・4・5では、1回25商品、A/B候補5件となる。

## 探索と停止条件

- A/B判定かつ検証済みの一意なキーワードだけを達成件数へ加算する。
- C/D、未検証、取得失敗、同一キーワードの再取得は件数へ加算しない。
- 1件目のA/Bを見つけても、目標件数未満なら次の未調査カテゴリへ自動で進む。
- 累積A/B件数が目標件数へ達した時だけ `winner-found` とし、自動探索を停止する。
- 候補プールを使い切った場合は、目標未達の件数を明示して `exhausted` とする。
- 外部接続エラーや利用上限では既存どおり一時停止し、取得済み結果と目標進捗を保存する。

今回すでに検証済みの `halloween reading shirt` は、同じハロウィン・Shirt探索の現在サイクルにおける1件目として引き継ぐ。目標5件へ変更した後は残り4件を探索する。

## 週次サイクル

- 探索履歴と検証結果は週をまたいで削除しない。
- 「今週の探索を開始」で新しいサイクルIDを作り、そのサイクルのA/B進捗を0件に戻す。
- 過去に調査済みのキーワードは再送せず、未調査の切り口から次の候補を作る。
- 月間目標設定と現在サイクルはローカル保存し、再起動後も復元する。

## データ構造

月間目標設定:

```js
{
  monthlyListingTarget: 100,
  researchRunsPerMonth: 4,
  listingsPerWinner: 5
}
```

連続探索状態へ追加する値:

```js
{
  cycleId: "cycle-...",
  targetWinnerCount: 5,
  winnerKeywords: [],
  completedAt: ""
}
```

設定値から算出できる表示用の値は保存せず、毎回再計算する。

## 既存データの移行

- 保存済み設定がない場合は100・4・5を使う。
- 旧状態の `winnerKeywords` は保持する。
- 旧状態が `winner-found` でも、保存済みA/B件数が新しい目標未満なら再開可能な状態として表示する。
- イベントまたは商品種別を変更した場合は、既存どおり別探索として勝ち候補進捗を初期化する。

## テスト

最低限、次を自動テストで確認する。

1. 100・4・5から、1回25商品、A/B目標5件を算出する。
2. 割り切れない値を切り上げる。
3. 0、負数、文字列、上限超過を安全な整数へ正規化する。
4. A/Bが1件でも目標5件なら探索を継続する。
5. 一意なA/Bが5件へ達した時だけ停止する。
6. 重複キーワード、C/D、未検証を達成件数へ含めない。
7. 旧 `winner-found` 状態を目標未達として再開できる。
8. 設定と進捗を保存・復元できる。
9. 現在のハロウィンB候補1件を保持したまま残り4件へ進める。

## 完了条件

- ユーザーが月間出品目標を入力できる。
- アプリが週次の必要出品数とA/B必要件数を自動計算して表示する。
- 連続探索がA/B目標件数未満では停止しない。
- 目標達成時だけ自動停止する。
- 月100商品設定で現在の1件を引き継ぎ、残り4件を実画面から探索できる。
